Final Project: Generative AI for work & research

AUTHOR
The Graph Courses • Cohort 2026 T3

Overview

For your final project, you will design and build an AI solution relevant to your work, research or personal projects, combining at least two themes from this course.

You will submit a 1–2 page document describing your solution and linking to it, and give a 4-minute live presentation with a demo in class.

Cohort Schedule & Help Sessions:
Weekly Workshop: Sundays 11:00–13:00 GMT or Weds 15:00–17:00 GMT
Help Sessions: 1 hour before each workshop

Course Themes

Here is a reminder of the main course themes and modules covered:

Theme 1: Websites & Presentations

Creating and hosting static sites using ChatGPT and GitHub Pages; structuring automated presentation decks with Gamma and Beautiful.ai.

Theme 2: Automated Data Analysis

No-code data analytics and plotting in R and Python via Cursor IDE; executive dashboard reporting with Bricks AI; data privacy and sanitization.

Theme 3: Text Processing & Literature Research

Executing LLM formulas inside Google Sheets and Excel; scientific knowledge synthesis using Consensus, Elicit, and Scite.

Theme 4: Custom GPTs & Interactive Chatbots

Model selection strategies; authoring custom instruction-grounded GPTs; building conversational decision flows in Botpress.

Theme 5: AI for Workflow Automation

Deterministic workflow automation via Make.com; triggering multi-step integrations; introduction to autonomous browser control agents.

Theme 6: Communication, Outreach & Media

Image and video generation; scalable vector diagram generation (SVG); visual communications with Canva AI.

Project Ideas

You are encouraged to build a project directly relevant to your daily work or research. Examples of multi-theme combinations include:

  • Automated Research Digest: An automated Make.com workflow connecting to Google Sheets to extract, categorize, and summarize weekly PubMed/arXiv literature into a live GitHub Pages feed (Themes 1, 3, 5).
  • Clinical Registry Query Assistant: An interactive Botpress chatbot grounded in trial protocol documents that feeds structured patient queries into a sanitized R data pipeline (Themes 2, 4).
  • Executive KPI Pipeline: A Cursor-driven analytical pipeline that takes raw operational CSVs, performs statistical summaries, and generates an SVG chart embedded into an executive summary webpage (Themes 1, 2, 6).

Submission Instructions

Please submit your project deliverables via the student portal before the presentation date:

  1. 1–2 Page Document (PDF or Markdown): An executive summary detailing your problem statement, tool architecture, failure recoveries, and live URLs to your solution.
  2. Live Access Link: A functional link (e.g., GitHub repository, hosted GitHub Pages URL, published Botpress bot, or Make.com blueprint export).
  3. Demo Slides: A concise 3-to-4 slide deck supporting your 4-minute presentation.

Frequently Asked Questions

Can I work in pairs or groups?

Projects are evaluated individually, though you are encouraged to collaborate and test each other’s tools during the Week 7 peer feedback sessions.

What if I miss a live workshop?

All workshops are recorded. However, you must attend at least 5 live sessions across the term to earn the 10% attendance credit.

Do I need coding experience?

No. The course focuses entirely on no-code tools and AI-assisted scripting where you guide the model rather than writing code manually.
